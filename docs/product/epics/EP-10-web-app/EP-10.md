# EP-10 — The photographer's web app

- **Subproject:** 001-luna-crm
- **Status:** draft
- **Covers requirements:** none yet — **proposed `R-30`** (`R-25`–`R-29` are already proposed by
  `EP-06`–`EP-09`). Amending the PRD is the owner's call.
- **Added:** 2026-10-15 — `ADR-024`

## Goal
A photographer manages shoots in the browser on a computer as fully as in the iOS app, at
`app.lunashoots.com`, laid out for a wide screen.

## Rationale
`ADR-021` decided the web app on 2026-10-04 but tied it to file hosting, which paused. The owner
wants it now, on its own (chat, 2026-10-15), and `EP-07` will need it later anyway.
