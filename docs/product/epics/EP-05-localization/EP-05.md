# EP-05 — Localization

- **Subproject:** 001-luna-crm
- **Status:** draft
- **Covers requirements:** R-10

## Goal
Every registered user gets a Ukrainian-first product by default, with the option to switch to
English, matching the audience this product is built for
(`00-intake/s02-2026-08-22/transcript.md`, lines 396–416).

## Rationale
`prd.md` R-10 is a sourced constraint, not a persona pain — the owner decided this directly,
including the explicit exclusion of Russian. It applies across every other epic's UI, so it is
called out on its own rather than repeated in each one.

## Stories
| ID | Story | Status |
|---|---|---|
| US-014 | UI defaults to Ukrainian for registered accounts | draft |
| US-015 | Switch UI language to English | draft |

`US-012` originally covered both of these as one story; split on 2026-08-22 because "defaults
to Ukrainian" (a passive state) and "switch to English" (an active user action) are two
independently-testable capabilities, not one. `US-012` is retired — see its file for the
pointer, and `CLAUDE.md`, Retired IDs.

## Out of scope
- Russian-language UI — deliberate exclusion, not an oversight
  (`00-intake/s02-2026-08-22/transcript.md`, lines 412–416).
- Any other language — not requested.
- Language switching for unregistered crew/client link views (EP-03, EP-04) — resolved as out:
  those views stay Ukrainian-only (owner's answer in chat, 2026-08-22).

## Dependencies
EP-01 — a language preference belongs to a registered account.

## Acceptance
Both stories accepted: a new registered account defaults to Ukrainian (US-014), and switching
to English (US-015) changes all UI text without needing to re-register or lose data.

## Open questions
None — resolved (see Out of scope).
