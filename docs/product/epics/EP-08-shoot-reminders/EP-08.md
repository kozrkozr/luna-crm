# EP-08 — Shoot reminders

- **Subproject:** 001-luna-crm
- **Status:** draft
- **Covers requirements:** none yet — **proposed `R-28`** (`R-25`–`R-27` are already proposed by
  `EP-06`, `EP-02` and `EP-07`). Amending the PRD is the owner's call.
- **Added:** 2026-10-05, from beta feedback

## Goal
The shoot creator is reminded of upcoming shoots on their phone — the evening before, and a few
hours before each one — without opening the app.

## Rationale
A beta tester asked for it (2026-10-05): «чи приходять від нього пуш повідомлення? Наприклад,
зйомка з клієнтом через 2 години? Це було б зручно) за день до зйомки та за годину або дві)».
`US-030` lists reminders as out of scope, and `US-035` defers notifications to "a separate
story, and probably its own epic" — this is that epic, for reminders only.

## Stories
| ID | Story | Status |
|---|---|---|
| US-041 | Get reminded of upcoming shoots | draft |

## Out of scope
- **Reminding crew or clients.** They have no app; the creator only (owner, chat 2026-10-05).
- **A push when a crew member confirms or declines.** The in-app bell already records it
  (`20260906120000_notifications.sql` in the build repo); a push for it is not wanted for now
  (owner, chat 2026-10-05).
- **Per-shoot reminder settings** — one set of settings for all shoots (owner, chat 2026-10-05).

## Dependencies
`US-030` — the start time the reminders are counted from. `US-039` (`EP-07`, paused) will need
server-sent push; this epic does not, but both share the one iOS permission.

## Acceptance
`US-041` accepted.
