# EP-04 — Client view

- **Subproject:** 001-luna-crm
- **Status:** draft
- **Covers requirements:** R-11, R-22, R-23, R-24 (R-12 retired)

## Goal
A client can see what's planned for their shoot — including who's on the crew, minus their
private notes — and see where things stand on raw files and finished photos, without
contacting the photographer directly and without being able to change anything
(`01-discovery/personas.md`, "Also interacts with the product — Client").

## Rationale
`decisions/ADR-006-*.md` settled the client's v1 scope at view, explicitly not propose
references. `US-024` and `US-025` were added from Ilona's first review round
(`03-design/reviews/r01-2026-08-23/notes.md`) — a lightweight placeholder-or-link section, not
the actual file hosting still deferred by `decisions/ADR-005-*.md` (amended by
`decisions/ADR-008-*.md`). In the **second** review round
(`03-design/reviews/r02-2026-08-23/notes.md`), the owner removed `US-011` (reacting to
references) entirely — see `decisions/ADR-009-*.md` — and added `US-026` (viewing crew details
minus notes), reversing the earlier "crew-only" line on that capability. Confirming attendance
was considered and left out (`02-product/prd.md`, Users).

## Out of scope
- Client confirming attendance — considered, not confirmed for v1 (`prd.md`, Users; `scope.md`,
  Deferred).
- Client reacting to references — tried, then removed (`decisions/ADR-009-*.md`).
- Client proposing their own references — considered and declined
  (`decisions/ADR-006-*.md`).
- ~~**Actual file hosting** for raw files or finished photos~~ — **undeferred 2026-10-03** by
  `decisions/ADR-020-*.md`. `US-024`/`US-025` now show hosted files; the creator's side is
  `EP-07`. Crew seeing the files stays out of scope for now.
- Client seeing a crew member's notes — that field stays crew-only (`US-023`); `US-026` is
  explicitly the same idea minus that one field.
