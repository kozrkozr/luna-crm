# Release 1.0.0 (build 2) — TestFlight

What changed: `CHANGELOG.md`. Build 1 was archived from `f34cb40` on 2026-10-01; this build is
`main` as of the checklist's commit.

Prod: Supabase `hjijvyensphkwyystgyq` (eu-central-1), link surface `lunashoots.com` (Pages `main`).

## Why the order matters

The production database is shared by **build 1 already on testers' phones** and by build 2.

- `20261006140000` (`US-044`) rewrites crew roles and reference categories from «Фотограф» to
  `photographer`. Build 1 cannot translate keys: **from the moment it runs, build 1 and the
  current `lunashoots.com` show raw keys** (`photographer`, `light`). Its triggers keep build 1's
  *writes* correct; only reading is affected.
- So: upload build 2 and let it finish processing **before** pushing migrations, then push the
  migrations, deploy the web, and release the build to testers — back to back.
- The other four migrations are additive and harmless to build 1.
