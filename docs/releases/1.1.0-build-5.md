# Release 1.1.0 (build 5) — a big update from the photographers' feedback

Since `v1.0.1-build.4`. What changed: `CHANGELOG.md`.

Version goes to **1.1.0**: new features, not only fixes (owner, 2026-10-19). Build **5**.

Prod: Supabase `hjijvyensphkwyystgyq`, link surface `lunashoots.com`.

## Why the order matters again

Unlike 1.0.1, this one is **not app-only**:
- **Two prod migrations** the new build reads: `20261018120000_reference_shot_at.sql`
  (`shoot_references.shot_at`, `US-068`) and `20261018180000_shoot_currency.sql`
  (`shoots.currency`, `US-070`). Without them the references tab and every shoot query fail. Old
  builds are safe on the new schema (a trigger fills `currency`). App Review uses prod, so both
  go **before** the build is submitted. `20261016120000_beta_tester_own_end_date.sql` is already
  on prod (2026-10-16) — confirm with `supabase migration list`.
- **The link surface changed**: «Маршрут» replaced the copy button on the link views (`US-034`),
  so `npm run deploy:web` goes to prod after the migrations.
- **New native code**: `expo-contacts` (`US-065`) and `modules/address-search` (`US-067`) —
  a clean prebuild, not a JS-only reload.
