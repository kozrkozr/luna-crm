# Release 1.0.1 (build 4) — minutes in a shoot's time

The first update after the launch. What changed: `CHANGELOG.md`. Since `v1.0.0-build.3`.

Version goes to **1.0.1**: 1.0.0 is released on the App Store, and Apple accepts no more builds
for it. Build **4**.

Prod: Supabase `hjijvyensphkwyystgyq`, link surface `lunashoots.com`.

## Why this one is simple

**App-only.** No migration, no Edge Function, no change to the link surface — checked with
`git diff --stat v1.0.0-build.3..HEAD`: `supabase/` untouched, and the link views use nothing
that changed (`formatDayMonthYear` is new, the subscription screen is its only consumer). So
nothing on prod moves before or after the build, and the order of steps does not matter the way
it did for builds 2 and 3.

## Checklist

### 1. Before the build
- [ ] `main` pushed and clean: `git status`
- [ ] `npm run typecheck`
- [ ] `app.config.ts`: `version` is `'1.0.1'`, `ios.buildNumber` is `'4'`
- [ ] **No `.env.local` in the repo root** (it is `.env.local.off` since 2026-10-15). Expo reads
      it whatever `variant.mjs` sets, and it holds the local backend's address

### 2. Build and upload
- [ ] `npm run prebuild:prod` — regenerates `ios/` as Luna Shoots against `.env.prod`
- [ ] Xcode → `ios/LunaShoots.xcworkspace` → Any iOS Device → Product → Archive
- [ ] Distribute App → App Store Connect → Upload
- [ ] App Store Connect → TestFlight: build 4 finishes processing (export compliance is answered
      in `app.config.ts`, so it should not ask)

### 3. Check build 4 on a phone, against prod (TestFlight)
- [ ] New shoot → the time grid: 08:00 then 09:00 gives 08:00 – 09:00
- [ ] «Початок» 14:30, «Завершення» 16:00 → 14:00 half-filled, 15:00 whole, the summary
      «1 год 30 хв»; save, reopen → the same
- [ ] Edit a shoot without changing its time → no «Перетин із …»
- [ ] Profile → «Підписка» on a beta-list account → «Доступ до» with the year

### 4. App Store Connect — the 1.0.1 version
- [ ] Apps → Luna Shoots → **+** next to iOS App → version `1.0.1`
- [ ] Build → build 4
- [ ] **What's New in This Version**, both localizations — the text is the owner's to approve
      (CLAUDE.md rule 1); a draft:
