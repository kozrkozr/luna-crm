## Why the order matters

The production database is shared by **build 2 on testers' phones** and by build 3.

- `20261010120000_view_mode` makes the database refuse every create, edit and delete for an
  account without access. Build 2 knows nothing of access: from the moment it runs, **every tester
  not on the beta list gets a failed save in build 2**, with no paywall to explain it.
- So the migrations go out **on launch day, after the release is approved**, together with the
  launch date and the beta list — and testers are told to install Luna Shoots from the App Store
  the same day.
- Everything else (RevenueCat, secrets, functions, the build itself) can be done earlier.
